🔐 Segurança & Sessão

Autenticação de usuário único com hash PBKDF2-SHA256 (150.000 iterações) e criptografia AES-GCM dos dados usando o código de 7 dígitos como chave derivada.

⚠️ Sem recuperação: por design, não existe "esqueci minha senha". Se perder senha OU código, os dados são irrecuperáveis. Mantenha o JSON exportado como backup em local seguro.
ℹ️ Sobre o Sistema

Dtechmaster Admin v2.1 · Seguro
• Login de usuário único (senha + código de 7 dígitos)
• Hash PBKDF2-SHA256 (150k iterações) + salt aleatório
• Dados criptografados com AES-GCM 256-bit
• Sessão em sessionStorage com timeout de 15 min
• Rate limiting progressivo contra força bruta
• Sanitização XSS em todos os campos
• CSP (Content-Security-Policy) aplicada
• Logo DTECH MASTER (SVG) padrão + upload customizado
• Loja pública continua sem login (catálogo aberto)
